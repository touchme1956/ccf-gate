【なぜやるか】
門の roic は **のれん除外版** ＝ NOPAT ÷ (自己資本 + 有利子負債 − のれん − 無形資産)。
買収で伸びた会社は自己資本の大半がのれん＋無形なので、**分母が縮退して桁で暴れる**ことがある。
加えて採取器に「有利子負債タグが無い年を debt=0 と読む」バグがあった（絶対のルール7・是正済み）。
既存パックの値はこの両方の影響を受けている可能性がある。

【最重要 — 先入観を持つな。値は上にも下にも動く】

【検算のしかた】
原本は SEC EDGAR の最新10-K（外国民間発行体は20-F）。User-Agent に fortis5280@gmail.com を付け、
レート制限 10req/s を守る。`https://data.sec.gov/api/xbrl/companyfacts/CIK{10桁}.json` が最速。
貸借対照表・損益計算書から実額を拾い、直近年（可能なら5年分）について:
  ・実効税率 = 法人税等 ÷ 税引前利益
  ・NOPAT   = 営業利益 × (1 − 実効税率)
  ・roic（のれん除外） = NOPAT ÷ (自己資本 + 有利子負債 − のれん − 無形資産)
  ・roicg（のれん込み） = NOPAT ÷ (自己資本 + 有利子負債)
  ・有利子負債 = 長期借入金(1年内含む) + 短期借入金 + **リボルビング/コマーシャルペーパー** +
                 ファイナンスリース債務
    ※`LongTermDebtNoncurrent` だけを見ると **LinesOfCreditCurrent / CommercialPaper /
      ShortTermBorrowings** を取りこぼす。IDXX で実際に起きた。**必ず本文のBS表を読め。**
  ・nde = (有利子負債 − 現金同等物) ÷ (営業利益 + 減価償却費)
  ・roict = 5年系列の 直近−最古 が +2pt超でup / −2pt超でdown / 間はflat

【判定線（HEI・SPGI・RELXで確立）】
  ・IC が **負** → のれん除外ROICは定義上算出不能。**roic を null 化**
  ・IC が **自己資本の2割未満**、または **5年系列が桁で振れる（最大÷最小が2倍超など）**
    → 識別力が無い。**roic を null 化**

  ・**IC が健全（自己資本の2割以上）で系列も安定なら、60%を超えていてもそれが実測。そのまま採用せよ**
  ・現在値が原本と食い違うなら実測値へ直す。**上にも下にも直せ**
