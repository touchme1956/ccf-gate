# 盲検読解の指示書（A1 再投資の余地 / A2 資本配分の規律）

事前登録: out/angles4_prereg.json（この指示書は事前登録の刻みを写したもの。刻みを変えてはいけない）

## あなたの仕事
渡された番号 ID ごとに `/home/user/ccf-gate/_angles_data/blind/{ID}.txt` を読み、2つの刻みを採点する。
中身は **2013年前後の米国上場企業の年次報告書（10-K/20-F）の抜粋**で、社名とティッカーは `[COMPANY]` に置き換えてある。

## 絶対に守ること
- **読んでよいのは渡された ID のファイルだけ**。リポジトリの他のファイル（out/ の JSON・株価・リターン・台帳・CLAUDE.md など）を開かない。Web を検索しない。
- **その会社のその後（株価・成長・買収・倒産など、2013年より後に起きたこと）を採点に使わない。** 会社を推測できても、抜粋に書いてあることだけで採点する。
- 採点には**抜粋からの逐語の引用**を必ず付ける（100 と 50 は引用が無いと無効になる）。引用は抜粋の文をそのまま、40〜300字で。途中を省くときは `...` を使う。
- 判断できる記述が無ければ `null`。無理に埋めない。

## 刻み（事前登録のまま）
### runway（再投資の余地）
- **100**: 稼いだ現金の大半を高い利回りで再投資し続けられる根拠が原本にある。自社の売上が市場規模に比べて小さいと数字で述べる（自社シェア<15% 等）か、新しい市場・地域・製品への拡大が現金の主な使い道として具体的に書かれている。かつ成熟・飽和の記述が無い
- **70**: 成長の余地はあるが限定的。市場は伸びているが主力は成熟している／拡大の記述が一般論にとどまる／再投資と株主還元が半々
- **50**: 再投資の余地が乏しい。市場が成熟・飽和・縮小と原本が述べる、または現金の主な使い道が配当と自社株買いで、その理由として投資機会の少なさを述べる
- **null**: 判断できる記述が無い

### capalloc（資本配分の規律）
- **100**: 規律の根拠が原本にある。投資・買収に明示的な基準（ROIC・回収期間・ハードルレート等）を持つ、または自社株買いを本質的価値・株価水準と結び付けて述べる。かつ大規模な希薄化・連続する大型買収の記述が無い
- **70**: 普通。特段の基準は述べないが、無理な買収や大きな希薄化の記述も無い
- **50**: 規律を欠く兆候。大型買収の連続とその減損、株式の大量発行、買収による規模拡大を戦略の中心と述べる、自社株買いは希薄化の相殺としてだけ述べる
- **null**: 判断できる記述が無い

## 採点が終わってから（漏れの検査）
各社について「どの会社だと思うか」を `guess` に書く（分からなければ空文字）。**採点を先に確定させてから答えること。** これは判定には使わない。

## 納品
`/home/user/ccf-gate/_angles_data/reads/batch_{K}.json` に JSON の配列を書く（K は指示された班番号）:
```json
[{"id": 1234, "runway": 70, "runway_quote": "…", "runway_why": "日本語で1-2文", "capalloc": 100, "capalloc_quote": "…", "capalloc_why": "…", "guess": "…"}]
```
全 ID を1つずつ入れる（読めなかった ID も runway/capalloc を null にして入れる）。書き終えたら件数だけ報告する。
