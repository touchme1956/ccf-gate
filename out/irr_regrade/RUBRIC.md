# 再採点の規約（門 v9.9.144 ＋ 85の6検問）

あなたは**引用文だけ**を見て、その一文が今日の門の irr の刻みのどれを支えるかを採点する。
会社名・元の刻み・株価・結末はいっさい渡されていない。**推測して補わないこと。**

irr が測るのは一つだけ——**顧客が当社から他社へ乗り換えるとき、費用と時間を負うのは誰か。**

## 刻み

**85（認証・規格ロック）** — 次の全部を満たすときだけ:
- 引用が「**顧客の側が** 再認定・再試験・再検証をやり直す（費用と時間を負う）」と述べている
- **断定**である（will / must / generally maintains / are required to のような事実の記述）
- **向きが正しい**。次はすべて 85 にならない:
  - 当社が受ける認証（自社のFDA承認・ISO・FAA PMA・特許・ライセンス）
  - 当社が自社の仕入先を認定する話
  - 当社が新規顧客を取るときに認定を取りに行く負担（＝当社が外側にいる）
  - 「当社が認定を失えば当社の売上が減る」（損をするのは当社）

**70（高摩擦移行困難）** — 顧客側の再認定までは言っていないが、**摩擦の機構を名指し**している:
複数年の購買義務 / 消耗品の専用性（専用・純正でないと使えない）/ データ移行・再教育の費用 /
設置基盤（据え付けた装置・保管した資産の上に商売が乗る）/ 工程・業務フローへの組込 /
解約率・更新率の実数 / 物理的な固着（隣接・埋設・配管等）

**50（代替容易）** — 次のいずれか:
- 機構の名指しが無い
- 一般的な競争記述だけ（highly competitive / many competitors / we compete on price など）
- 向きが逆（費用を負うのが当社）
- **願望形だけ**（we work closely with / we strive to / our success depends on / we seek to）
- 自社の強み・品質・ブランドの自慢だけで、乗り換えの費用に触れていない

## 出す欄（項目ごと）
- `id`
- `rung`: 85 / 70 / 50
- `mech`: 顧客側の再認定 / 複数年の購買義務 / 消耗品の専用性 / データ移行・再教育 / 設置基盤 / 工程への組込 / 解約率・更新率の実数 / 物理的固着 / なし
- `dir`: 顧客が負う / 当社が負う / どちらでもない
- `tense`: 断定 / 願望形 / 該当なし
- `conf`: high / med / low
- `why`: 30〜80字。**引用の中の語を必ず挙げる**

## 禁じること
- 会社を推測してその知識で採点すること（**引用文に書いてあることだけで裁く**）
- リポジトリの他のファイルを読むこと（渡されたバッチの JSON だけを読む）
- 迷ったときに上へ倒すこと。**迷ったら下の刻みへ倒す**（85 は特権を伴うので、証拠が断定でなければ 70 以下）
