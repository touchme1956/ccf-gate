# 日本株 門2審査（v4厳格版・2026-07-25 やり直し）

## なぜやり直したか
v3以前の審査は堀(rep/irr/dur)の基準が「極困難/困難」という言葉だけで客観的な物差しがなく、
恣意的に高く付けられた。実害として **ラクス(楽楽精算)を rep70/irr80 と採点し 84.5 で
ASML(81.8) を上回らせた**。国内SaaSがEUV独占を上回るのは明らかに誤り。
旧結果24社は全て無効とし `out/jp/_superseded_v3/` へ退避した。

## v4で守る規律（門のⅡ実行手順に全文あり）
- **反証テスト**: 堀を上げる前に①現存競合を実名で3社挙げ②追随できない理由を原本の事実で述べる。
  書けなければ下の段。各銘柄の _meta.hanshou に記録する。
- **上限規則**: 競合を実名で挙げられる→rep≤60 ／ 移行年数・費用の原本記載なし→irr≤50 ／
  国内専業(海外30%未満)→f2≤65 ／ ブランド由来→dur≤55 ／ シェア%が原本になければdom=null ／
  2008年を上場で経験していない→p2≤75 ／ 5年ROICのσを原本計算できない→p1≤75
- **参照アンカー**: ASML(irr85/rep100/dur100) ResMed(85/80/85) Microsoft(70/80/85) 国内SaaS(70/60/75)
  自分の採点をこの並びに置いて検算し、矛盾したらやり直す。
- **提出前の自己点検**: 格80超なら「なぜASML級か」を一文で言えるか。言えなければ堀が甘い。
