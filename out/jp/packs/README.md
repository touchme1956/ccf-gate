→ 買収で買った売上が利益を生まず償却。acq5(買収規律)・roict/gmt=down・p4減点で回避。

## 8136 サンリオ 精査（2026-07-25・81.2最上位 → 79.9堅実に訂正）
初回81.2は cagr=38.8(EDINET 3年成長)を使っていたが、これは**コロナ後の回復リバウンド**。
原本で確認した結果、より重大な事実が判明:
- **FY2014に営業利益210億円でピーク(3期連続最高益)→その後7期連続で減収**
  →キャラクターIPのブーム→凋落を実際に一度やっている(出典: 日経, Business Insider)
- through-cycle成長(peak-to-peak) = 210億(FY2014)→778億(FY2026)/12年 = **11.5%**
  (直近4年の38.8%はリバウンドであり巡航ではない。アドバンテスト/ASMLと同じ規律)
- p1を50→35へ(7期連続減収の実績=ROIC安定性は低い)

訂正後: **79.9 堅実**(投下閾値75は超える)。感度は79.4-80.9で最上位/堅実の境界上。
OBIC(65-81で乱高下)と違い、どう振っても75は割らない頑健さがある。

**判定を左右する唯一の争点**: moatdecay(堀の崩壊)。yesにすると**59.9 失格**(S1キル)。
現在は過去最高益・成長34%・利益率拡大中ゆえ門の定義では no が正しいが、
2014-2021の凋落は「この堀は崩れうる」という履歴の証拠。今の40%営利率・34%成長が
再びピークである可能性は排除できない。

## 8136 サンリオ 門2審査プロトコル準拠版（2026-07-25）→ **78.0 堅実**
81.2最上位 → 79.9 → **78.0**。原本(決算短信PDF)を実際に読み、根拠のない定性を空欄にした結果。

### 原本から確認できた事実（決算短信 2026年3月期中間期・pdftotextで抽出）
- **ロイヤリティが売上の49.5%**（434億/876億）＝資本を使わず伸びるライセンスが本体
- 純現金 **1,146億円**（現金1,241億 − 短期借入51億 − 長期借入43億）→ p3=95の根拠
- **のれんは「重要性が乏しいため記載を省略」**＝買収依存でない（ナカニシと対照的）→ acq5=0
- 「北米・中国を中心にすべての地域で伸長」＝シェア趨勢+ → f3=75（R&D比率は未開示ゆえ片方のみ+）
- 海外が売上の40%、アジア営業利益+96.2% → f4=80（隣接の地域展開が売上5%超で成長）
- Gugenka子会社化（小規模）、Sanrio+会員292万人
- 海外連結子会社の決算期は1-12月＝親会社と3か月ズレ（会計上の注意点）

### 空欄にした項目（原本に記載がなく憶測を避けた）
- **dom（支配シェア%）**: 決算短信に市場シェアの記載なし → null。
  dom=70と仮に置くと78.0で不変（このスコアではdomは効いていない）。
- R&D/売上・TAM浸透率: 短信に記載なし → f2は保守側65、f3は片方+の75で据え置き
- accr（NI−OCF）: 中間短信のCF計算書から未取得 → p4は中立寄り80

### 依然として残る限界（正確さの上限）
1. **有価証券報告書の「事業等のリスク」を読めていない** — erosion/disrupt/expiry/geopolの
   一次根拠がない（短信には当該項目がない）。有報の取得が次の精度向上策。
2. p1=35は7期連続減収（日経・Business Insider＝二次ソース）に基づく。
   5年ROICのσを原本から計算できていない。
3. 中間期の短信であり通期の原本ではない。
