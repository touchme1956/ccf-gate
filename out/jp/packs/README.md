## 7716 ナカニシ — 門判定 25.7「回避」（2026-07-25）
病名「谷」（営利率≥15・成長≥5だがROIC 8-15%）の正体を定性で裁いた結果＝**投資期の谷ではなく買収の失敗**。
- 売上 44,857→81,179百万円(+81%) だが営業利益は 13,750→14,090(+2.5%)で横ばい
- 営業利益率 30.65%→17.36%（半減）／FY2025は純損失▲2,398百万円
- のれん 108→21,934→5,391百万円＝**約160億円の減損**（大型買収の失敗が表面化）
- 門式ROIC(報告) 7.9% ／ 現金控除 14.3% ／ 純現金 36,025百万円
→ 買収で買った売上が利益を生まず償却。acq5(買収規律)・roict/gmt=down・p4減点で回避。
