## 母集団の作り方（アメリカ株の門0と同じ手順）
1. EDINETの業種タグ `semiconductor` で **40社**を抽出
2. タグ漏れの主要銘柄を手で追加（芝浦メカトロニクス・ジャパンマテリアル・メック・SUMCO・レゾナック・santec・東洋合成・フェローテック・浜松ホトニクス）→ **33社**
3. FY2019/2021/2022/2023/2024/2025 の XBRL 実額（売上・営業利益・営業CF・自己資本）をパネル化
4. **門式ROIC = 営業利益×0.79 ÷（自己資本＋有利子負債）** を全社・全年で計算

## v4が効いた場面（自己点検の記録）
**① レーザーテックを66.6へ自己是正（−7.8）**
当初 dom=100／rep=80 と採点したが、根拠が二次ソース（ブログの「シェア100%」）だった。
**会社IRページ（lasertec.co.jp/ir/individuals/euv.html）を直接読んだところ「世界唯一」「シェア100%」の記載はなく**、
あるのは「EUVマスク欠陥検査に関する基盤技術の確立に努めてまいりました」のみ。v4規則
「シェア%が原本になければdom=null／競合を実名で挙げられればrep≤60」に従い dom=null・rep=60 へ是正。

**② アドバンテストを原本の記載でirr 50→70へ引上げ（+4.5）**
インベスターズガイド2025年10月28日 Chapter3 に会社自身の記述:
> 「選定されたテスタを変更することは、顧客にとってデバイスの開発・評価・量産のすべての環境を
> 再構築することと同義であり、大きな追加コストがかかる」

移行の**年数・費用の数値**はないので irr=85（認証/規格ロック）には上げず、70（高摩擦・移行困難）まで。
**同じ原本を全文検索したがシェア%の記載はなく dom=null**（統合報告書2021の「テスタ市場シェア目標
2027年度50%以上」は目標であって実績ではない）。

**③ 旧採点との差**: アドバンテストは旧・日本株プロトコルで **77.1 堅実／押し目監視** だった。
旧採点は dom80・irr80・rep82 と原本のない高評価で、p2=70（実際はFY2010リーマンで営業赤字）だった。
v4で **68.4 回避**。**押し目監視から外れる。**

## 重要な留保（採点者の限界）
US側の保有・監視銘柄（NVDA・MSFT・ASML・KLAC等）は**v4より前のプロトコルで採点されている**。
したがって「日本の半導体は全部75未満、USの半導体は75超」という並びには、
**同じ物差しで測っていない部分が残る**。ASMLはEUV独占が自社アニュアルレポートに書かれており
v4を通しても高得点だが、他のUS銘柄は再点検しないと厳密な比較にならない。
