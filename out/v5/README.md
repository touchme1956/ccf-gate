# v5（証拠規則）— 全銘柄 通し直し（2026-07-26）

## 正本に入れた3つの規則変更（index.html の審査プロトコル US版・日本株版の両方）
1. **〈証拠規則〉判定軸を「会社が自己開示したか」→「第三者が検証できる具体的事実があるか」へ**
   採用可: ①会社開示 ②業界標準の第三者統計（TechInsights/VLSI/Gartner/IDC/Nilson Report/富士キメラ等）を**出典名つきで** ③規制当局・裁判所の認定。
   採用不可: 個人ブログ・掲示板・出典不明の二次まとめ・審査者の印象。
   v4は自己開示を要求したため、シェアを誇る日本のIR文化を優遇し、訴訟リスクでシェアを書かない米国10-Kを不当に罰していた（実測: 米国14社の10-Kシェア開示はゼロ）。
2. **irr70 は「年数・費用の数値」または「代替に何が要るかの構造的事実」で可**（認証再取得・顧客の量産プロセス再構築・design-in）。
3. **rep は競合の数ではなく「無制限の資金と人材で何年かかるか」で測る。**
   80＝①出荷実績を持つ他社2社以下 **または** ②追随に10年超かつ累計R&D/設備投資$10B級（数値で示す） **または** ③規制・IPで実質封鎖。
   ※アンカー（ASML/ResMed/Microsoft）は**検算用の並びであって免除ではない**と明記した。

### 一度失敗して直した箇所（記録）
最初 rep を「当該チョークポイントに出荷実績を持つ競合が3社以上→rep≤60」とした。
これは rep を competitor-count 判定にしてしまい **dom と二重計上**になり、ほぼ全社が rep60 に潰れ、
プロトコル自身のアンカー（Microsoft rep80・AWS/Google現存）とも矛盾した。上記3の形に直した。

## 前回との違いで大きいもの
- **NVDA が 69.3 → 75.0 で復帰**。v4は10-Kにシェア%がないだけでdom=nullにしていた。Bloomberg集計の86%を採ったのが効いた。
- **東京エレクトロンが日本株で初めて75を超えた（76.9）**。
- **MSFT は 74.8 で 0.2 だけ足りない**。アンカー免除を外した効果。**この差は誤差の範囲**であり、閾値を割ったという事実以上の意味を読むべきではない。
- **ラクスは 78.2 → 73.7 に下がった**。第三者調査では首位ですらなかった。v5は日本株を甘くする改定ではない。

## 残る問題（エンジン側・ユーザー判断が要る）
**5038 eWeLL 78.9 が Microsoft・NVIDIA・ResMed より上に並んでいる。**
訪問看護SaaSの小型株が世界4位に来るのは序列として不自然。原因は堀の採点ではなく
**採点エンジンが ROIC(0.42) を MOAT(0.38) より重く配点している**ことで、
無借金・自己資本比率78.8%・ROE37.6%・accr−4.2%といった小型株の綺麗な財務が
規模でROICが薄まる大企業を上回る。これはプロトコル（審査基準）ではなく
**エンジンの配点**の問題なので、掟に従い変更していない。直すなら別途の指示が要る。
